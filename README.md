# Digital Payments & UPI Transaction Analytics

An end-to-end Data Analytics project focused on analyzing UPI transaction data to understand transaction trends, growth patterns, UPI app performance, customer transaction behavior, and key business insights.

## Project Objective

The main objective of this project is to transform raw UPI transaction data into meaningful insights that help understand digital payment growth, app performance, transaction segments, and overall UPI market trends.

## Technologies Used

- **Python** – Data cleaning, preprocessing, EDA, and data analysis
- **SQL** – Data querying and analysis using different SQL queries
- **Excel** – Storage and handling of the cleaned dataset
- **Power BI** – Interactive dashboards, visualization, and business insights

## Project Workflow

1. **Data Preprocessing – Python**
   - Handled missing values
   - Checked and handled duplicate records
   - Removed unnecessary columns
   - Renamed column names
   - Prepared the dataset for analysis

2. **Clean Data Storage – Excel**
   - Stored the cleaned and processed dataset in Excel for further analysis and use.

3. **Exploratory Data Analysis – Python**
   - Analyzed transaction trends
   - Studied transaction volume and value
   - Compared transaction segments
   - Identified important patterns in the data

4. **Data Analysis – SQL**
   - Performed data analysis using different SQL queries
   - Analyzed app-wise, year-wise, quarter-wise, and month-wise performance
   - Compared B2C and B2B transactions
   - Identified top-performing UPI apps

5. **Visualization & Insights – Power BI**
   - Created interactive dashboards
   - Visualized transaction trends and growth
   - Compared UPI app performance
   - Analyzed transaction segments
   - Generated final business insights
